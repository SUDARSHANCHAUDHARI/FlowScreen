# FlowScreen Roadmap

## Current Direction

FlowScreen should evolve into a browser-first signage product where venue-specific scenes, motion styles, and playback behavior feel operationally useful.

## Near-Term Improvements

- improve screen-stage realism
- tighten preview proportions across devices
- improve control panel hierarchy
- add better active-state contrast in mode and scene pickers
- add clearer messaging for autoplay state

## Next Features

- real media upload
- fullscreen presentation mode
- scene timing and transitions
- multiple screen layouts
- playlist-like program flow

## Add-Ons

- venue template library
- interactive hotspot overlays
- daypart scheduling presets
- motion intensity controls
- screen-safe typography presets

## Good To Have

- presentation mode for client demos
- quick mock assets bundled with the app
- simple content duplication workflow
- kiosk-friendly touch targets
- animated standby / attract loop mode

## Production Readiness Later

- asset persistence
- deployment target strategy per screen
- hardware and kiosk considerations
- environment config and ops docs
- analytics and remote management later
